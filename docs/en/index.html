One launcher, three simple ideas

Plume answers a precise need: playing with your mods from a tool that doesn’t weigh on your machine.

1

Light by design

Written in Rust with Tauri, with no heavy embedded browser. While you play, the launcher steps aside and comes back when the game stops or crashes.

2

Mods without the hassle

Modrinth search matched to your version, dependencies installed automatically, files verified with a SHA-512 checksum.

3

Honest and transparent

No ads, no store, public code. Official Microsoft sign-in: you need an account that owns Minecraft: Java Edition.

Our story

Plume was born from a simple wish: a launcher that opens fast, feels good to use and stays light, like the big launchers of the moment but without their weight.

The project started as a mockup, then a minimal launcher able to download and start the game. Each version adds what was really missing day to day: several instances, mods, readable logs.

Plume is an independent project. It is neither affiliated with nor endorsed by Mojang or Microsoft.

What Plume can do

Everything listed here exists in the current version.

▦

Isolated instances

Vanilla, Fabric, Quilt, Forge or NeoForge, each with its own mods, worlds and settings. One-click duplication, play time and disk size.

⬡

Modrinth mods

Mods, shaders and resource packs: search, install with dependencies, enable, update. Mods you add by hand show up too.

☺

Microsoft accounts

Several accounts, with your skin’s head. Offline play for up to 30 days after the last verification.

⚡

Performance

Eco, Balanced and Performance profiles, memory per instance, tuned Java settings. An already prepared version starts much faster.

☕

Automatic Java

Plume downloads the right Java for each Minecraft version. You can also point to your own.

≡

Live logs

Game console, log, crash reports. Warning and error filters, one-click copy.

✎

Customization

Light, dark or system theme, six accent colors, compact mode, game window size.

↻

Built-in updates

The launcher updates itself (AppImage on Linux, Windows and macOS), without downloading everything again.

🌐

Multilingual

French and English, with an open translation system: each language shows its translated percentage.

⎔

Four loaders

Fabric, Quilt, Forge and NeoForge, set up for you. Forge and NeoForge use their official installer.

📦

Modrinth modpacks

Install a modpack in one click, or drop a .mrpack file onto the window: loader, mods and files are set up with checksum verification.

⚗

Plume Lab

For mod and pack authors: automatic launch test, startup time, memory, CPU, errors, mixins and missing dependencies, with a comparison between two runs.

⇪

Export and drag-and-drop

Export an instance as a .zip to share it. Drop a .jar onto the window to add it to your mods.

🛡

Reliable downloads

Verified checksums, retries on failure, allowed hosts only.

All official Minecraft versions are offered. The oldest ones are experimental and less tested.
